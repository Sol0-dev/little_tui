little-tui

A self-hosted, terminal-based coding agent

What is little-tui?

little-tui is an autonomous coding agent that runs in your terminal. It is built on OpenRouter and uses an automated tool loop modeled after the OpenRouter Agent SDK's callModel pattern. Written in pure Python (stdlib + requests), it allows you to interact with AI models to perform coding tasks directly from your command line.

Key Features

Interactive REPL

Run little-tui to start an interactive session where you can chat with the agent, issue commands, and iterate on code.

One-shot Headless Runs

Execute a single prompt non-interactively: little-tui --prompt "summarize the README" or pipe input via stdin.

Powerful Toolset

The agent can read, write, and edit files; list directories; glob search; grep content; run shell commands (with permission); and get the current datetime. All file operations are confined to a workspace directory for safety.

Configuration & Safety

Configure via environment variables or a JSON file. Dangerous tools (like shell) are disabled by default and must be explicitly allowed per run or interactively in the REPL. The agent operates with step and cost limits to prevent runaway execution.

Session Logging

All interactions are logged as JSONL files under ~/.local/share/little-tui/sessions/ for replay and auditing.

Getting Started

  1. Install: pip install -e .[dev] (inside the repository)
  2. Set your OpenRouter API key: export OPENROUTER_API_KEY=sk-or-v1-...
  3. Run the agent: little-tui

See the README.md for detailed usage, configuration, and examples.
